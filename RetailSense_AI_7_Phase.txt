RetailSense AI: Sales Analytics and Intelligent Business Insights
Project Plan — 7 Phases (Free and Open-Source Stack)

STACK — FREE TOOLS ONLY
- Frontend: React + Vite
- Backend: Python + FastAPI
- Data processing: Pandas
- Machine learning: Scikit-learn
- Charts: Plotly (plotly.js / react-plotly.js)
- Database: SQLite
- Local AI: Ollama with a locally downloaded model
- API requests: built-in fetch (no paid service required)
- Version control: Git
- Code editor: Visual Studio Code
- Testing: pytest and React Testing Library / Vitest
All of these can be used without paid subscriptions. Ollama runs locally; hardware requirements depend on the selected model. Avoid paid hosting or paid AI APIs.

PHASE 1: PROJECT SETUP AND ARCHITECTURE
Goal:
Create the initial React frontend and Python backend using free tools.

Tasks:
- Install Node.js, Python, Git, and a code editor.
- Create a React application with Vite.
- Create a FastAPI backend and Python virtual environment.
- Install free dependencies: Pandas, Scikit-learn, FastAPI, Uvicorn, and a SQLite driver.
- Add Plotly support to the React frontend.
- Create a clear frontend/backend folder structure.
- Define how React will call FastAPI endpoints.
- Keep all core features runnable locally without paid services.

Deliverables:
- React and FastAPI applications running locally.
- Dependency files and project structure.
- Feature list and API plan.

PHASE 2: CSV UPLOAD AND DATA CLEANING
Goal:
Import sales data and prepare it for analysis.

Tasks:
- Build a React CSV upload page.
- Create a FastAPI upload endpoint.
- Validate column names, data types, and file format.
- Use Pandas to handle missing values, duplicates, invalid dates, and inconsistent formats.
- Derive fields such as month, year, and order value where possible.
- Display validation errors and upload status in React.
- Store data locally in SQLite when persistence is needed.

Deliverables:
- CSV upload feature.
- Data validation and cleaning pipeline.
- Clean dataset ready for analysis.

PHASE 3: SALES KPIS AND DASHBOARD
Goal:
Display an interactive sales overview.

Tasks:
- Calculate total revenue, order count, units sold, and average order value using Pandas.
- Create FastAPI endpoints that return summary metrics as JSON.
- Build KPI cards and dashboard layout in React.
- Use Plotly charts for sales, orders, and category performance.
- Add filters for dates, products, categories, and customers when those fields exist.
- Add loading, empty, and error states.
- Test all features locally without paid analytics services.

Deliverables:
- Interactive React dashboard.
- KPI API endpoints and Plotly charts.
- Working filters.

PHASE 4: SALES TRENDS AND PRODUCT PERFORMANCE
Goal:
Analyze sales trends and identify top products.

Tasks:
- Aggregate revenue and orders by month and year with Pandas.
- Show monthly trends with Plotly.
- Rank products by revenue, quantity sold, and order count.
- Compare categories and highlight growth or decline where the data supports it.
- Add product tables and detail views in React.
- Apply dashboard filters consistently across results.

Deliverables:
- Monthly trend charts.
- Top-product and category reports.
- Backend endpoints for trend and product analysis.

PHASE 5: CUSTOMER SEGMENTATION
Goal:
Group customers by purchasing behavior using free machine-learning libraries.

Tasks:
- Create customer-level features such as total spending, purchase frequency, and average order value.
- Scale numeric features using Scikit-learn.
- Apply KMeans clustering or another suitable Scikit-learn method.
- Evaluate and inspect clusters before assigning business-friendly descriptions.
- Create API endpoints for segment counts and profiles.
- Display segment charts and summaries in React.
- Explain limitations if customer IDs or purchase history are unavailable.

Deliverables:
- Customer segmentation model and pipeline.
- Segment summaries and visualizations.
- API endpoints for customer analysis.

PHASE 6: LOCAL AI ASSISTANT WITH OLLAMA
Goal:
Answer questions about the sales dataset without paying for a hosted AI API.

Tasks:
- Install Ollama locally and download a compatible free model.
- Build a FastAPI service to communicate with Ollama.
- Create a React chat interface.
- Calculate factual answers using Pandas or controlled, parameterized SQL queries.
- Give the model calculated results as context so it can explain the figures.
- Add suggested questions and business insight summaries.
- Return a clear message when the dataset cannot answer a question.
- Never execute arbitrary code or SQL generated by the model.
- Keep AI optional so the dashboard works when Ollama is unavailable.

Deliverables:
- Local AI chat assistant.
- Business insight summaries grounded in computed metrics.
- No paid AI API dependency.

PHASE 7: TESTING AND FINAL DEMONSTRATION
Goal:
Verify the application and prepare it for academic presentation.

Tasks:
- Test valid, malformed, empty, and incomplete CSV files.
- Verify calculations using small datasets with manually checked answers.
- Test filters, charts, clustering, SQLite storage, and AI responses.
- Use free test tools such as pytest and Vitest / React Testing Library.
- Improve layout, responsive behavior, and error messages.
- Write a README explaining installation and how to run frontend, backend, and Ollama locally.
- Include a sample dataset with non-sensitive or synthetic data.
- Document the architecture, algorithms, limitations, and future improvements.
- Prepare a demonstration from upload to dashboard, segmentation, and AI Q&A.

Deliverables:
- Tested local application.
- README and setup instructions.
- Sample dataset and final demo plan.

SUGGESTED 2–4 WEEK PLAN
- Week 1: Phases 1–3 — setup, data import, cleaning, and dashboard.
- Week 2: Phase 4 and Phase 5 — trends, product reports, and customer clustering.
- Week 3: Phase 6 — Ollama integration and AI insights.
- Week 4 if needed: Phase 7 — testing, polish, and presentation.

SUGGESTED API ROUTES
- POST /api/datasets/upload — upload and validate a CSV.
- GET /api/datasets/{dataset_id}/summary — return KPI metrics.
- GET /api/datasets/{dataset_id}/trends — return monthly trends.
- GET /api/datasets/{dataset_id}/products — return product rankings.
- GET /api/datasets/{dataset_id}/customers/segments — return customer segments.
- POST /api/datasets/{dataset_id}/assistant — answer a dataset-grounded question.
- GET /api/health — check backend status.

IMPORTANT FREE-STACK NOTES
- Do not use Streamlit.
- React is the frontend; FastAPI is the backend.
- Start with Pandas; PySpark is optional and usually unnecessary for a student-scale prototype.
- SQLite is a free local database and requires no separate database server.
- Ollama runs models locally, but model size affects RAM, disk, and speed.
- You can develop and demonstrate the full project locally without buying hosting or AI API credits.
- If you later publish it online, check the hosting provider's current free-tier limits; do not assume hosting will remain free.
